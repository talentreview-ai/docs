TalentReviewAI is an AI-native hiring workspace. Candidates search open roles in
plain English; recruiters post a job and let AI screen resumes, match
candidates, and run interviews.

These docs cover the **Agent API**, the surface AI agents use to discover, read,
and act on jobs.
